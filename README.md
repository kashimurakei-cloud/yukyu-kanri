# 有給管理アプリ（すこやか歯科医院）

React/Vite + Firebase（Authentication + Firestore）で作った有給管理アプリです。
スタッフは自分の有給だけを見られ、院長は全員を見られます。

---

## これは何ができるアプリか

- **スタッフ**：ログインすると自分の有給残（○日分）と取得履歴が見える。取得を登録できる。
- **院長**：全スタッフの状況を一覧。各人の履歴閲覧、計画年休の一括反映、スタッフ登録、通知確認ができる。
- 有給の付与日・付与日数は、入職日と週の出勤日数から**自動計算**（労基法の比例付与テーブル準拠、時効2年）。
- 計画年休を登録すると、その日が勤務日のスタッフに各自の分で自動反映。
- スタッフが取得を登録すると院長に通知（アプリ内）。

## セットアップ手順

### 0. 前提
- Firebaseプロジェクトを作成済み（別紙「firebase-setup-手順書」のステップ1〜6を完了していること）
- 院長のAuthアカウントと、staffコレクションに role=owner のレコードがある状態
- Node.js が入っていること（Mac mini の場合 `node -v` で確認）

### 1. このフォルダで依存をインストール
```bash
npm install
```

### 2. .env を用意
`.env.example` を `.env` にコピーし、Firebaseの値を入れる（すでに取得済みの値を入れてあります。プロジェクトを作り直した場合は差し替えてください）。
```bash
cp .env.example .env
```

### 3. ローカルで動作確認
```bash
npm run dev
```
表示されたURL（http://localhost:5173 など）をブラウザで開く。
院長のメール＋パスワードでログインできるか確認。

### 4. GitHub にアップロード
annual-todo と同じ要領で、新規リポジトリを作って push。
※ `.env` は `.gitignore` で除外済み（GitHubには上がりません）。

### 5. Vercel でデプロイ
1. Vercel で「New Project」→ このリポジトリをインポート
2. **Environment Variables** に、`.env` の6項目を1つずつ登録（重要：Vercelは.envを読まないので手動登録が必要）
   - `VITE_FIREBASE_API_KEY` など6つ
3. Deploy
4. 公開URL（例：yukyu-kanri.vercel.app）でログイン確認

## スタッフの追加方法（運用開始時）

スタッフ1人につき2ステップ：

### ① ログインアカウントを作る（Firebaseコンソール）
1. Firebaseコンソール →「Authentication」→「Users」→「ユーザーを追加」
2. そのスタッフのメールアドレスと仮パスワードを入力
3. 発行された **User UID** をコピー

### ② スタッフ情報を登録（このアプリの院長画面）
1. 院長でログイン →「スタッフ管理」タブ →「＋ 新規スタッフ」
2. さきほどの **Auth UID** を貼り付け
3. 氏名・入職日・週の出勤日数・1日あたりの分数・曜日ごとの勤務分を入力
4. 保存

これでそのスタッフは、配ったメール＋パスワードでログインでき、自分の有給だけが見える状態になります。

> パスワードは院長も知らない状態が理想。スタッフには「初回ログイン後、パスワードを変更してね」と伝えるか、ログイン画面の「パスワードを忘れた場合」から各自に再設定してもらってください。


## 注意点・既知の制約（第1弾）

- **取得記録の編集・削除UIは未実装**（登録のみ）。間違えた場合は当面Firebaseコンソールで直接修正。次弾で編集機能を追加予定。
- **メール通知は未実装**（アプリ内通知のみ）。希望があれば次弾でCloud Functions経由のメール通知を追加。
- **出勤率8割要件・年5日取得義務の自動判定は未実装**（院長の目視運用）。
- 繰越・時効は「付与日から2年で時効」の簡易版。古い付与から消化、などの精緻な管理は次弾で。
- ネット接続が必要（オフラインでは動きません）。
